## Justificativa Acadêmica

A justificativa acadêmica deste trabalho está relacionada à aplicação de conhecimentos de desenvolvimento web, banco de dados, organização da informação, análise de dados e visualização. O trabalho permite estudar um problema real e transformá-lo em uma proposta tecnológica, passando pelas etapas de levantamento, definição de requisitos, modelagem, construção de protótipo e avaliação inicial.

Estudos relacionados apontam que sistemas MES/ERP para PMEs são complexos, caros e representam overkill para fábricas de pequeno porte. A Manufatura 4.0 foca em grandes indústrias com sensores IoT, sem abordar a organização básica de dados. Já a análise de dados em PMEs apresenta uma lacuna entre "ter dados" e "usar dados", em decorrência da falta de ferramenta acessível.

O Tintas MGMT preenche essa lacuna ao propor uma solução web simples, de baixo custo e com deploy gratuito (Vercel + Supabase free tier), focada na organização dos dados antes de análises avançadas. A proposta estabelece uma base para futuro aprendizado de máquina e integração de sensores, possui RBAC nativo para separação de responsabilidades (produção, vendas, estoque, manutenção) e é extensível: o schema do Supabase permite adicionar sensores e ML sem refatorar o frontend.
